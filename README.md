# 拾漫 · 鸿蒙原生多源漫画阅读器

ShiMan · Native Comic Aggregation Reader for HarmonyOS

拾漫（ShiMan）是一款面向 HarmonyOS NEXT 的原生漫画聚合阅读器，致力于将多个漫画站点的内容统一整理到一个应用中，提供统一搜索、聚合书架、章节阅读、换源浏览和收藏管理等体验。项目以 ArkTS 为核心开发语言，强调无广告、无登录、无数据上传，专注于提供纯本地阅读体验与可扩展图源管理。

ShiMan is a native comic aggregation reader for HarmonyOS NEXT. It brings together content from multiple manga sources into a single app experience, offering unified search, cross-source discovery, chapter reading, source switching, bookmark collection, and reading progress tracking. Built with ArkTS, the project emphasizes privacy and simplicity: no ads, no login, and no data upload. Its design focuses on a lightweight native reading experience and extensible source configuration.

功能一览：多源发现 / 跨源聚合搜索 / 阅读中换源 / **星标收藏** / 书架与阅读进度 / 图源管理与自检。

- 包名：`com.manyu.reader`
- 目标平台：HarmonyOS NEXT（编译目标 API 22 / 6.0.2，向下兼容可在 5.x、7.0 上运行）
- 产物：`hap/manyu-1.0.0-unsigned-20261101.hap`（660 KB）
