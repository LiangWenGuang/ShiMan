## 核验方法与结果

使用 GitHub-hosted Ubuntu/Node 22 对不需要登录的公开页面执行真实 HTTP 请求，不依赖搜索引擎标题判断链路可用性，不尝试绕过付费墙或站点鉴权。探测脚本：`tools/probe-candidates-20261113.mjs`；可重复运行的独立准入脚本：`tools/ganma-smoke.mjs`。

|---|---|---|---|---|

## GANMA! 接入实现

- `sources/ganma.json`：`/web/search?keyword={kw}` 搜索；`/web/magazine/{slug}` 详情；`/web/reader/...` 公开目录与正文
- 搜索卡片和详情使用服务器返回的 HTML；公开目录去除「第1話を読む」按钮造成的首章重复
- 正文的 CDN 图片签名在服务器返回的内联 JSON 里，解析时恢复 `\\u0026` 为 `&`，对重复序列化图片去重，保留章节页 Referer
- 内置配置数量从 19 改为 20
- `tools/ganma-smoke.mjs` 在 GitHub Actions 上验证实际搜索、目录、图片 URL 和首图下载；`tools/engine-test/run.ts` 额外加入配置解析和正文正则的离线回归

## 本轮界面排版调整

1. **首页：** “当前/全部图源”与刷新按钮同一行，当前图源选择移到独立第二行，避免窄屏控件重叠。
2. **搜索：** 显示独立搜索进度卡、完成源数、匹配数量与可视进度条，区分命中与无结果状态。
3. **图源管理：** 新增已启用/已配置统计和“仅看启用”过滤，明确区分页面渲染型与直接解析型源；自检说明不夸大覆盖正文的程度。
4. **阅读器：** 首章/末章导航置灰并防止越界点击；保留所有阅读位置恢复和原始章节索引逻辑。

## 尚未验证及上线门槛

- GitHub Actions 离线与公开站点 smoke **不等于** DevEco ArkTS 编译，也不能证明 HarmonyOS 7 真机布局无异常。
- 真机回归须验证：GANMA 日文搜索、列表封面/签名过期、详情目录、36 页加载、快速切章、断点继续、窄屏首页图源栏、搜索进度条、源过滤和首末章导航。
- 不向 `main` 合并未经 DevEco 编译、真实 HarmonyOS 7 设备验收的改动。
