# ShiMan 漫画章节正序/倒序纠正（2026-11-14）

## 问题与根因

`SourceApi.detail()` 会将 HTML/JSON 章节统一传给 `normalizeChapterOrder()`，使内部 `chapter.index = 0` 代表最早章；详情页与阅读器的“正序/倒序”本来只控制目录**展示**。

旧版本检测要求全部有效章节号严格单调。遇到特别篇、番外、重制章、重复编号、插入页或卷号重置时，检测结果为 `null`，回退到图源 JSON 的固定 `chapters.reverse`。该配置与某本漫画真实排序相反时，不仅目录标签错，上一章/下一章阅读方向也会错。

## 本轮修复

1. **识别方向**：优先抽取明确的章节编号（`第1话`、`第十回`、`第１話`、`Chapter 12`、数字开头），跳过特别篇、更新日期与卷数；对相邻有效编号方向做多数投票；大跨度跳跃、混合或证据不足则不猜测。
2. **原配置兜底**：当无法可靠判断时才沿用该图源的 `chapters.reverse`，不做全量数字排序，保留番外篇的相对位置。
3. **单本漫画修正**：详情页“章节目录”和阅读器目录增加“纠正顺序 / 恢复自动”。修正结果写入 `Library` 的 `chapter_order_fixes`，按图源 ID + 漫画 ID 隔离；不改变其他漫画，也不改变全局目录显示偏好。
4. **阅读进度兼容**：按 `chapterId + chapterTitle` 优先找回上次阅读章；翻转后复制并重建 `ChapterBrief.index`，阅读器保持当前章节与已加载图片，更新进度新索引。
5. **界面区分**：`正序/倒序` = 只改变目录的显示先后；`纠正顺序` = 修复上一章/下一章的实际阅读方向。

## 自动回归

`tools/engine-test/run.ts`：正/倒序、含番外和重复章、中文数字、日文全角、混合歧义兜底、跨重排进度匹配、显示顺序与内部顺序隔离、日期/卷号防误识别。

`tools/engine-test/runtime.ts`：每本漫画独立设置、快速连续修正后的偏好落盘。

需要在 DevEco 和 HarmonyOS 7 实机继续核对实际站点目录，特别是整卷分组、章节无序号和手动修正后的重新进入行为。没有实际站点示例的情况下，不应声称所有 20 个源的所有作品都能被自动识别。
